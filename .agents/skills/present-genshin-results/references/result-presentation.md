# Result presentation checklist

- Name the exact party, rotation, simulator revision, game-version assumption, and evaluation mode.
- Separate total damage, DPS, reaction damage, reaction-labeled direct damage, reward, and rollout throughput.
- Show numerical or behavioral correctness alongside performance.
- Identify random effects, seeds, repetitions, aggregation, and uncertainty.
- For RL, include party catalog, deterministic/stochastic mode, invalid actions, episode count, and checkpoint compatibility.
- For optimization, include starting allocation, ER constraints, search method, convergence, and matched baseline.
- For mechanics, cite the source and label exact, simplified, custom, or deferred behavior.
