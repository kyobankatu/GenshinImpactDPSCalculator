# Evidence source contract

For each material rule record:

- claim and affected game version;
- source title, stable URL/identifier, publisher/author, date, and scope;
- canonical terminology and units;
- observed versus inferred fields;
- conflicting sources and the resolution rule;
- simulator choice: exact, simplified, custom, deferred, or unresolved;
- regression input, expected result, and tolerance.

Do not infer exact gauge, frame, rounding, proc, or targeting behavior from a translated display description alone. Separate source evidence from the implementation decision.
